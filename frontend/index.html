Visualize and run classic AI search algorithms

Breadth-First Search (BFS)

BFS explores all nodes at the current depth before proceeding to nodes at the next depth level. It is complete and optimal for unweighted graphs. Time complexity: O(V+E).

Depth-First Search (DFS)

DFS explores as far as possible along each branch before backtracking. Memory efficient but not guaranteed to find the shortest path. Time complexity: O(V+E).

Iterative Deepening DFS (IDDFS)

IDDFS combines the space efficiency of DFS with the completeness and optimality of BFS. It performs DFS to increasing depth limits until the goal is found.

A* Search Algorithm

A* finds the shortest path using f(n) = g(n) + h(n), where g(n) is the cost from the start and h(n) is the heuristic estimate to the goal. It is both complete and optimal when h(n) is admissible.

D* is an incremental heuristic search algorithm that handles dynamic environments. It efficiently replans paths when obstacles are added or removed without restarting from scratch.
